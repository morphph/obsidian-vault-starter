# learn/

Learning notes produced by the `/learn` command. Each session writes one file:
`<YYYY-MM-DD>-<kebab-topic>.md` — a mastery checklist + open gaps + key takeaways
for a blog, a Claude output, or pasted text/code you wanted to deeply understand.

Human-owned afterward — keep, prune, or graduate notes into `wiki/` or `drafts/` as
they prove useful.
