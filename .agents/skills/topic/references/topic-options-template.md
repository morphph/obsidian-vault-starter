# Topic options

Write 2–4 options. Make each one a different editorial bet.

```markdown
# Topic Options: <subject>

## Option 1 — <working title>

- **Thesis:** <one contestable sentence>
- **Reader:** <specific reader>
- **Promise:** <what changes for the reader>
- **Why now:** <time-sensitive reason>
- **Market gap:** <evidence from market-scan.md>
- **Research foundation:** <claims and original sources from research>
- **Different from:** <representative pieces and the distinction>
- **Author advantage:** <credible reason this version should exist>
- **Likely objection:** <strongest challenge>
- **Risk:** <thin evidence, crowded frame, narrow audience, etc.>
- **High-level shape:** <3–5 beats, not a full outline>

## Option 2 — ...

## Recommendation

<Recommend one option. Explain the upside, the cost, and what would change the recommendation.>
```

Reject options that merely rename the same thesis.
