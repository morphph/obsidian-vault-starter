# 全文自然译读（faithful full translation, canonical）

> `/ingest` step 3 **博文 / 文章 / 长推文类**源的结构（也是 `/learn-note` 的精读结构）。
> 演进：2026-07-07 从 12 段 study guide 切成"贴原文结构的精读"；2026-07-15 作者进一步拍板——**博文要的是接近全文的自然翻译,不是压缩重述**。
> 目标是 **读中文 ≈ 读原文全部**：作者读中文更快,这份译读是他学英文原文的主通道,同时是下游视频 script 的口语化底稿。
> **PDF / YouTube 视频不走这个**,走 `references/essence-extraction.md`(精要)。

**目的**：把英文原文**完整、忠实、自然地翻成中文**。读者读完这份中文,应该等于读完了原文——不丢论点、不丢例子、不丢数据、不丢过渡。像作者本人用中文写了一遍,而不是别人替他复述。

**核心原则**：

- **接近全文,不压缩**：目标是"读中文 ≈ 读原文全部"。原文的每一个论点、例子、数据、类比、乃至有信息量的展开,都要落到中文里。只允许省纯填充(如 "as I mentioned" 这类无信息回指、纯客套)。**宁可长,不可漏。**（对照旧规则:不再"压掉纯修辞与重复"——除非它确实零信息。）
- **保持原文人称与口吻**：原文第一人称 "I / we / my" 就译"我 / 我们 / 我的",第二人称 "you" 就译"你"。**绝不改写成"作者认为…""作者主张…""他建议…"这类第三方转述腔。** 你是在把原文翻成中文,不是在替读者转述作者。判准:读者应感觉像在读作者亲手写的中文原稿。
- **自然中文,不要翻译腔**：按中文表达习惯重组句子,不是逐词对译。可以拆长句、调语序、把英文被动改中文主动、把从句拆成短句——只要意思和语气不变。判准:中文母语者读起来觉得"这是中文",而不是"这是翻译"。
- **术语留英文原名**：概念首次出现给「中文译名 (English Original)」,之后可只用英文原名。不为翻译而翻译(prompt caching 就是 prompt caching)。
- **数据逐字保留**：所有数字、基准、百分比、专有名词逐字照搬（"102 features in 7 days" 不许变成「一周上百个功能」）。
- **金句双语**：最有冲击力的原句,除了译进正文,另在收尾以 EN + 中译各留一份(引语是日后写稿的弹药)。
- **解读克制**：个人评论/联想只允许出现在收尾的「与 vault 的连接」和「视频适配自评」。正文里不夹私货——正文的忠诚对象只有原文。

**完整结构**：

---

## 0. 元信息头

```
# 精读：{原文标题}
**作者**：{姓名 + 一句话身份/stake}
**来源**：{平台} · {日期} · [原文]({URL})
**原文字数**：约 {N} words · **译读预读时长**：约 {M} 分钟
**一句话主旨**：{一句话说清这篇讲什么、核心主张是什么}
```

`**一句话主旨**：` **逐字用这个字段名**——WF1 gate packet / learn_note.py 直接正则提取当 Hook,格式错了下游就断。认真写。

## 1. 正文（主体 · 全文自然翻译）

按原文章节顺序,每章：

```
## {章节序号}. {英文原题}（{中译}）
{该章的完整中文翻译:原文口吻、原文人称、自然中文,论证/例子/数据一条不落}
```

- 原文无小标题的（如长推文/散文体）,按其自然段落主题切块,块题用中文概括并注明「（原文无小标题,此为段落主题）」。
- 代码块/表格/清单：结构照搬,注释性文字中译。
- 原文配图：保留图片引用或用一句话描述图的内容（「图：…」）。

## 2. 收尾（正文之后,明确分隔）

```
---
## 精读收尾
- **一句话总结**：{可发推级别的压缩}
- **关键引语**：{3-5 条 EN + 中译,正文已出现的可汇总于此}
- **与 vault 的连接**：{[[wikilink]] ×2-4,一句话说明关联；先扫 wiki/index.md 确认页面存在}
- **视频适配自评**：{适合/不适合做白板讲解视频 + 一句话理由（概念结构是否可图示、论证是否有讲解张力）}
```

---

## 与图示的配合（S2/S3 起生效）

译读若配了白板图示（excalidraw-diagram skill 产出）,PNG 嵌在**最相关章节之后**：`![[{slug}-diagram.png]]`。图示步骤应对应原文的论证展开顺序（图是原文结构的空间化,不是另一套解读）。
